# Globas API

Руководство по обновлённому сервису проверки контрагентов.

## Основные модули

| Путь | Назначение |
|------|------------|
| `application.py` | Создание контейнера с подключением к базе и регистрация роутеров. |
| `dependencies.py` | Провайдеры `get_engine`, `get_checklist_service` и вспомогательные зависимости для хендлеров. |
| `api/routes/admin.py` | Административные эндпоинты (управление справочниками, тестовые данные). |
| `api/routes/company.py` | Клиентские эндпоинты: генерация отчёта, проверка контрагента, выдача чек-листа. |
| `models/` | Pydantic-схемы домена: `CompanyProfile`, `ChecklistItem`, `ChecklistReport`. |
| `services/checklist.py` | Бизнес-логика формирования чек-листа и расчёта рисков. |

## Поток обработки `/company/check`

1. **Получение зависимостей.** FastAPI инжектирует `ChecklistService` через `get_checklist_service`.
2. **Загрузка данных.** Сервис вытягивает информацию из БД (через SQLAlchemy-движок) и внешних источников.
3. **Построение отчёта.** Формируются отдельные блоки (регистрация, финансовый анализ, санкции и т. д.).
4. **Агрегация результата.** Pydantic-модель `ChecklistReport` собирает блоки и метаданные, которые возвращаются клиенту.

## Расширение

* Дополнительные проверки добавляются методом в `ChecklistService` и описанием в `models/checklist.py`.
* Повторно используемую бизнес-логику имеет смысл выносить в отдельные классы внутри `services/`.
* SQL-запросы лучше оформлять как функции-репозитории рядом с `db.py`, чтобы разгрузить сервис.
