# Legal AI Backend

Описание архитектуры обновлённого backend-а Legal AI.

## Основные модули

| Путь | Назначение |
|------|------------|
| `application.py` | Контейнер настроек и фабрика FastAPI-приложения. |
| `dependencies.py` | Функции доступа к контейнеру и сервисам анализа. |
| `api/routes/analysis.py` | Основные эндпоинты анализа документов и генерации ответов. |
| `api/routes/health.py` | Health-check и технические служебные маршруты. |
| `services/` | Обёртки над Ollama, Qdrant и другими внешними системами. |
| `startup.py` | Регистрация событий `on_startup` и `on_shutdown` (инициализация индексов, прогрев моделей). |

## Поток обработки запроса анализа

1. **Маршрут `/analyze`.** Обработчик принимает текст документа и параметры запроса.
2. **Инжекция зависимостей.** Из контейнера извлекается сервис анализа (`LegalAIService`).
3. **Векторизация и поиск.** Запрос проходит через Qdrant для поиска релевантных фрагментов базы знаний.
4. **Генерация ответа.** Ollama формирует осмысленный ответ и список рекомендаций.
5. **Формирование отчёта.** Pydantic-модель приводит результат к стандартизованному виду.

## Расширение

* Дополнительные источники знаний подключаются через новые провайдеры в `startup.py` и зависимости в `dependencies.py`.
* Чтобы добавить новый маршрут, создайте модуль в `api/routes/` и зарегистрируйте его в `api/__init__.py`.
* Для написания юнит-тестов можно инициализировать контейнер с тестовыми настройками и подменными клиентами.
